# План: Интеграция MAX-бота в SmsForwarder

## Цель
Дублировать входящие SMS в MAX-бота (через серверный API `platform-api2.max.ru`) в дополнение к текущей SMS-пересылке.

## Что нужно сделать

### 1. Создать ветку
- `git checkout -b feature/max-integration`

### 2. Добавить зависимости (build.gradle.kts)
- `implementation("com.squareup.okhttp3:okhttp:4.12.0")` — HTTP-клиент для вызовов MAX API

### 3. Добавить разрешение на интернет (AndroidManifest.xml)
- `<uses-permission android:name="android.permission.INTERNET" />`

### 4. Создать MaxBotClient.kt
Новый файл: `app/src/main/java/com/example/smsforwarder/MaxBotClient.kt`

Класс для отправки сообщений через MAX API:
- Метод `sendMessage(token: String, chatId: Long, text: String)`
- Endpoint: `POST https://platform-api2.max.ru/messages`
- Заголовок: `Authorization: <token>`
- Тело: `{ "chat_id": <chatId>, "text": "<text>" }`
- Обработка ошибок, логирование
- Вызов в отдельном потоке (coroutine или thread)

### 5. Добавить настройку токена бота (SettingsManager.kt)
- Добавить ключи: `max_bot_token` (string), `max_chat_id` (long)
- Значения по умолчанию: пустые (интеграция отключена)
- UI для ввода токена и chat_id в MainActivity

### 6. Интегрировать в SmsReceiver.kt
- После `sendSms()` добавить вызов `MaxBotClient.sendMessage()`
- Отправка только если токен и chat_id настроены
- Не блокировать основной поток — асинхронный вызов

### 7. Обновить MainActivity.kt
- Добавить поля ввода: "Токен MAX-бота", "Chat ID"
- Кнопка "Сохранить MAX настройки"
- Проверка: если токен настроен — показывать статус "MAX: подключён"

### 8. Обновить layout activity_main.xml
- Добавить EditText для токена MAX
- Добавить EditText для chat_id
- Добавить кнопку сохранения MAX-настроек

## Файлы для изменения
| Файл | Действие |
|------|----------|
| `app/build.gradle.kts` | Добавить OkHttp |
| `app/src/main/AndroidManifest.xml` | Добавить INTERNET |
| `app/src/main/java/com/example/smsforwarder/MaxBotClient.kt` | **Новый** |
| `app/src/main/java/com/example/smsforwarder/SettingsManager.kt` | Добавить MAX-настройки |
| `app/src/main/java/com/example/smsforwarder/SmsReceiver.kt` | Вызов MaxBotClient |
| `app/src/main/java/com/example/smsforwarder/MainActivity.kt` | UI для MAX-настроек |
| `app/src/main/res/layout/activity_main.xml` | Добавить поля ввода |

## Проверка
1. Собрать проект: `./gradlew assembleDebug`
2. Убедиться, что нет ошибок компиляции
3. Протестировать: отправить SMS → должно прийти в MAX-бота
