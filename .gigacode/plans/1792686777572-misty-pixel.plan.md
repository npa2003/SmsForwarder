# План реализации: SMS Forwarder

## Обзор
Android-приложение для автоматической пересылки входящих SMS на заданный номер. Сервис работает в фоне, запускается при загрузке устройства.

## Файлы для создания/модификации

### Новые файлы:
1. `app/src/main/java/com/example/smsforwarder/SettingsManager.kt` — SharedPreferences для настроек (номер пересылки, флаг первого запуска, слот SIM)
2. `app/src/main/res/drawable/notification_icon.xml` — векторная иконка для уведомления

### Модифицируемые файлы:
1. `app/src/main/AndroidManifest.xml` — добавить PACKAGE_REPLACED, проверить все разрешения
2. `app/src/main/res/values/strings.xml` — добавить строковые ресурсы
3. `app/src/main/java/com/example/smsforwarder/MainActivity.kt` — first-launch логика, проверка разрешений
4. `app/src/main/java/com/example/smsforwarder/BootReceiver.kt` — автозапуск, фильтрация PACKAGE_REPLACED
5. `app/src/main/java/com/example/smsforwarder/SmsReceiver.kt` — использование SettingsManager, fallback отправки
6. `app/src/main/java/com/example/smsforwarder/ForwarderService.kt` — Foreground Service, отправка SMS

## Шаг 1: SettingsManager
- Singleton object, инициализация через `init(Context)`
- Ключи: `first_launch` (boolean, default true), `forward_number` (String, default из BuildConfig), `target_sim_slot` (int, default 0)
- Метод `markFirstLaunchComplete()`

## Шаг 2: AndroidManifest.xml
- Добавить `<action android:name="android.intent.action.PACKAGE_REPLACED" />` в BootReceiver
- Убедиться в наличии: RECEIVE_SMS, SEND_SMS, READ_PHONE_STATE, BOOT_COMPLETED, FOREGROUND_SERVICE, POST_NOTIFICATIONS (uses-permission)

## Шаг 3: notification_icon.xml
- Vector drawable с иконкой сообщения

## Шаг 4: strings.xml
- Добавить все строки для UI, уведомлений, настроек

## Шаг 5: MainActivity
- Вызов `SettingsManager.init(this)` в onCreate
- Проверка `isFirstLaunch`: если true — показывать кнопки проверки разрешений и запуска сервиса; если false — скрыть кнопки
- Массив разрешений: RECEIVE_SMS, SEND_SMS, READ_PHONE_STATE, POST_NOTIFICATIONS (API 33+)
- `onRequestPermissionsResult`: при успешной выдаче всех разрешений — `markFirstLaunchComplete()`
- Кнопка запуска сервиса — `startForegroundService()` с action "START_FOREGROUND"

## Шаг 6: BootReceiver
- Обработка BOOT_COMPLETED, QUICKBOOT_POWERON, PACKAGE_REPLACED (фильтр по package name)
- Проверка `isServiceRunning()` перед стартом
- Запуск ForwarderService с action "START_FOREGROUND"

## Шаг 7: SmsReceiver
- Инициализация SettingsManager в onReceive
- Использование `SettingsManager.forwardNumber` и `SettingsManager.targetSimSlot`
- Определение SIM-слота из intent
- Fallback: если старт сервиса не удался — отправка SMS напрямую через SmsManager
- Форматирование сообщения: `[SIM] номер дата\ntext`

## Шаг 8: ForwarderService
- Foreground Service с notification channel (IMPORTANCE_LOW, без звука/вибрации)
- Обработка action "FORWARD_SMS" — извлечение данных, отправка SMS через SmsManager
- `START_STICKY` для автоперезапуска
- Убрать manual restart в onDestroy (система сама перезапустит)
- Уведомления о результате пересылки

## Верификация
1. Сборка: `./gradlew assembleDebug` — без ошибок
2. Первый запуск: показать кнопки проверки разрешений и запуска сервиса
3. Выдача разрешений: все 4 разрешения (RECEIVE_SMS, SEND_SMS, READ_PHONE_STATE, POST_NOTIFICATIONS)
4. Запуск сервиса: foreground notification появляется
5. Получение SMS: пересылка на номер из настроек
6. Перезагрузка устройства: сервис запускается автоматически
7. Повторный запуск приложения: UI минимизирован (кнопки скрыты)
