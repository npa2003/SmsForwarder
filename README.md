# SMS Forwarder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Android Version](https://img.shields.io/badge/Android-8.0%2B-brightgreen)

Приложение для Android, которое автоматически пересылает входящие SMS с указанной SIM-карты на заданный номер телефона. Работает в фоновом режиме.

## Возможности

- 📱 **Выбор SIM-карты** - отслеживание первой или второй SIM
- 🔄 **Автоматическая пересылка** - мгновенная отправка полученного SMS на указанный номер
- 🚀 **Фоновая работа** - стабильная работа с уведомлением в статус-баре
- 🔔 **Уведомления** - информирование о результатах пересылки
- 📋 **Форматирование** - добавление служебной информации (оператор, время, отправитель)
- 🔄 **Автозапуск** - автоматический старт после перезагрузки телефона

## Требования

- Android 8.0 (API 26) и выше
- Наличие SIM-карты (для работы с двумя SIM нужен соответствующий телефон)

## Установка

1. Скачайте последний APK из [раздела Releases](https://github.com/npa2003/SmsForwarder/releases)
2. На телефоне разрешите установку из неизвестных источников
3. Откройте скачанный файл и установите приложение
4. При первом запуске выдайте все запрошенные разрешения:
   - Доступ к SMS
   - Доступ к телефону (для определения SIM-карты)
5. Нажмите кнопку "Запустить сервис"
