# SMS Forwarder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Android Version](https://img.shields.io/badge/Android-8.0%2B-brightgreen)

Приложение для Android, которое автоматически пересылает входящие SMS с любого номера на заданный номер телефона. Работает в фоновом режиме.

## Возможности

- 📱 **Пересылка со всех номеров** - принимает SMS с любого номера и любой SIM-карты
- 🔄 **Автоматическая пересылка** - мгновенная отправка полученного SMS на указанный номер
- 🔧 **Настройка номера в приложении** - изменение номера пересылки прямо в интерфейсе
- 🚀 **Управление сервисом** - кнопки запуска и остановки фонового сервиса
- 🔄 **Автозапуск** - автоматический старт сервиса после перезагрузки телефона
- 📝 **Чистый формат** - пересылается только номер отправителя, дата/время и текст сообщения

## Требования

- Android 8.0 (API 26) и выше
- Наличие SIM-карты (для работы с двумя SIM нужен соответствующий телефон)

## Установка

1. Скачайте последний APK из папки `app/build/outputs/apk/debug/`
2. На телефоне разрешите установку из неизвестных источников
3. Откройте скачанный файл и установите приложение
4. При первом запуске выдайте все запрошенные разрешения:
   - Доступ к SMS
   - Доступ к телефону
5. Нажмите кнопку "Запуск" для старта сервиса

## Настройка

Номер для пересылки задаётся в файле `.env`:

```
FORWARD_NUMBER=+79169641310
```

Также номер можно изменить прямо в приложении через поле ввода.
